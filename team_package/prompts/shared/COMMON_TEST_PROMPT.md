## Antigravity Standard Testing Prompt

---

```text
المهمة: تنفيذ الفحص والتحقق الشامل للمرحلة المنفذة.

خطوات التحقق الإلزامية:
1. الفحص الساكن للكود (Static Code Analysis):
   - التأكد من خلو الملفات من أخطاء الـ Linting والـ Type Checking.
2. تشغيل اختبارات الوحدة (Unit Tests):
   - تشغيل جميع ملفات الاختبار المرتبطة بالمرحلة.
   - التأكد من اختبار حالات النجاح (Success)، والفشل (Failures)، والقيم غير الصالحة (Edge Cases).
3. فحص البناء (Build Verification):
   - تشغيل أمر البناء الرسمي والتأكد من خلوه من الأخطاء والتحذيرات.
4. تقرير نتيجة الاختبار (Test Report):
   - توثيق عدد الاختبارات الناجحة وحالة التغطية ونتيجة البناء.
```
