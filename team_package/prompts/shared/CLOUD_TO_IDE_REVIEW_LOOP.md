# حلقة المراجعة بين الذكاء السحابي والـ IDE | CLOUD_TO_IDE_REVIEW_LOOP.md
## نظام الحضور الجامعي الذكي (University Attendance System)

---

## خطوات حلقة المراجعة والتحقق (8-Step Review Loop):

1. **مخرجات Antigravity (Antigravity Output):** يقوم المطور بنسخ الكود المنفذ وتقرير المرحلة واختباراتها من Antigravity IDE.
2. **المراجعة السحابية (ChatGPT / Cloud Review):** يُرسل الكود والتقرير إلى المساعد السحابي باستخدام `CLOUD_REVIEW_PROMPT.md`.
3. **نتيجة المراجعة (Review Result):** يُصدر المراجع السحابي تقييمه (`PASS` أو `FAIL`) مع قائمة الملاحظات المصنفة.
4. **تحليل الملاحظات (Antigravity Analysis):** يقوم المطور بإعادة تقرير المراجعة إلى Antigravity لتحليله وفهم الإصلاحات المطلوبة.
5. **خطة الإصلاح (Fix Plan):** يُنشئ Antigravity خطة إصلاح جراحية دقيقة لمعالجة الملاحظات دون المساس ببقية الكود.
6. **موافقة المطور البشري (Human Approval):** يراجع المطور الخطة ويوافق عليها صراحة.
7. **تنفيذ الإصلاح (Fix Execution):** يُطبق Antigravity الإصلاحات بدقة في نطاق الملفات المسموحة.
8. **إعادة الاختبار والاعتماد (Re-Test & Handoff):** تشغيل الاختبارات للتأكد من زوال الأخطاء وتوثيق المرحلة بتقرير التسليم.
