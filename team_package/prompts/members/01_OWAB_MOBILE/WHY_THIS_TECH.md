## 01 — أواب النزيلي (Flutter Mobile Application)

---

### 1. لماذا Flutter لتطبيق الهاتف؟
- **الهدف:** توفير واجهات ذات أداء عالي 60fps تدعم اللغة العربية (RTL) بشكل أصيل ومتناسق مع شاشات الهواتف المختلفة.
- **البدائل:** React Native أو Native Android/iOS.
- **سبب استبعاد البدائل:** الحاجة لكود موحد، أداء رسومي فائق، ودعم ممتاز للعمل دون اتصال (Offline-first).

### 2. لماذا Dio & SecureStorage للـ API والتخزين؟
- **Dio:** يدعم الـ Interceptors لإرفاق توكنات JWT وتجديدها تلقائياً عند انتهاء صلاحيتها.
- **FlutterSecureStorage:** لتشفير توكنات النفاذ ورموز التفعيل على مساحة التخزين الآمنة بالهاتف (KeyStore / Keychain).
