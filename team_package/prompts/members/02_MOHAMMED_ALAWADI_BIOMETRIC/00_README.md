# دليل البدء الشامل | 02 — محمد العواضي
## نطاق المسؤولية: محرك التحقق الحيوي (Biometric Verification Engine)

---

### 1. من هو العضو وما مهمته؟
- **العضو:** محمد العواضي (Biometrics & AI Engine Developer).
- **المهمة:** تصميم وبناء محرك التحقق الحيوي (`BiometricService`) والتقاط وفحص جودة الصورة واستخراج القوالب المشفرة (`BiometricTemplate`) والمطابقة المحلية وإرجاع حالات التحقق الرسمية.

### 2. القواعد الصارمة لمحرك البصمة:
- البصمة لا تسجل الحضور في قاعدة البيانات، بل تعيد نتيجة تحقق فقط (`VERIFIED`, `REJECTED`, `REVIEW`, `LOW_QUALITY`, `ENGINE_ERROR`).
- عزل المحرك خلف واجهة `BiometricService` واستخدام نمط `Adapter`.
- حظر الادعاء بنسب دقة دون تجارب فعلية موثقة.
- ممنوع التدخل في كود الخادم المحلي أو واجهات الطلاب العامة.
