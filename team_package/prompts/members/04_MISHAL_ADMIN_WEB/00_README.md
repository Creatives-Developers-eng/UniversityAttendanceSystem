# دليل البدء الشامل | 04 — مشعل الحاج
## نطاق المسؤولية: لوحة تحكم العمادة (Admin Flutter Web)

---

### 1. من هو العضو وما مهمته؟
- **العضو:** مشعل الحاج (Flutter Web Admin Developer).
- **المهمة:** بناء لوحة التحكم الإدارية المركزية للعمادة وإدارة الهياكل الأكاديمية والمستخدمين والتقارير وسجلات التدقيق عبر واجهة ويب متجاوبة بالكامل تتصل بـ REST API.

### 2. القواعد الصارمة:
- كافة البيانات تُجلب عبر REST API، وممنوع الاتصال المباشر بقاعدة بيانات PostgreSQL.
- الالتزام التام بنظام التصميم `UI_UX_SYSTEM.md` ودعم RTL والـ Material 3.
- توفير الحالات الخمس لكل جدول وشاشة: Loading, Empty, Error, Retry, Success.
