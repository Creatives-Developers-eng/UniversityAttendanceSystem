# 🛠️ دليل تهيئة بيئة الباك إند (Workspace Setup)

### 📌 المتطلبات والتشغيل:
1. التأكد من تثبيت Node.js (v18+) و PostgreSQL.
2. الانتقال إلى مجلد الباك إند:
   ```bash
   cd backend
   npm install
   ```
3. تشغيل الـ Migrations وتوليد عميل Prisma:
   ```bash
   npx prisma generate
   npx prisma migrate dev
   ```
4. تشغيل خادم التطوير:
   ```bash
   npm run start:dev
   ```
5. فتح واجهة Swagger في المتصفح: `http://localhost:3000/api/docs`
