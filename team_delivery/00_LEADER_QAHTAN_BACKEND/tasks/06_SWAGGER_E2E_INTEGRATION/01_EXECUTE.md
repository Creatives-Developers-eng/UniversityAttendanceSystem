# 🚀 برومبت التنفيذ: التوثيق التفاعلي واختبارات التكامل الشاملة (Swagger & E2E)
## 👤 القائد: قحطان الشجاع (Qahtan Alshagea)
### 🏛️ المسؤولية: تطوير الباك إند المركزي

### 🎯 الهدف البرمجي:
توثيق وتفعيل كافة مسارات الـ API عبر Swagger UI التفاعلية، وتشغيل مصفوفة اختبارات التكامل الشاملة E2E.

### 📂 المسار المستهدف بالكتابة:
`backend/test/ و backend/src/main.ts (Swagger Config)`

### ⚡ التعليمات لـ Antigravity IDE:
1. إعداد توثيق Swagger لكل مسار مع نماذج الطلب والاستجابة، وكتابة سيناريوهات اختبارات الـ E2E لتدفق الحضور الكامل.
2. الالتزام الصارم بمعمارية NestJS الرسمية وقواعد Prisma المعتمدة.
3. التحقق من تطابق المدخلات والمخرجات مع عقود `team_package/api_contract/`.
