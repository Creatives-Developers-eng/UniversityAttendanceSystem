# 🚀 برومبت التنفيذ: محرك التقارير الأكاديمية ومراجعة الأعذار (Reports & Excuses API)
## 👤 القائد: قحطان الشجاع (Qahtan Alshagea)
### 🏛️ المسؤولية: تطوير الباك إند المركزي

### 🎯 الهدف البرمجي:
حساب نسب الحضور والغياب للمقررات والشعب، إصدار كشوفات الحرمان للطلاب المتجاوزين لنسبة 25%، ومسارات رفع واعتماد الأعذار الطبية.

### 📂 المسار المستهدف بالكتابة:
`backend/src/reports/ و backend/src/justifications/`

### ⚡ التعليمات لـ Antigravity IDE:
1. بناء محرك تجميع الإحصائيات (Aggregation Service) ومسارات تقديم وقبول/رفض الأعذار الطبية.
2. الالتزام الصارم بمعمارية NestJS الرسمية وقواعد Prisma المعتمدة.
3. التحقق من تطابق المدخلات والمخرجات مع عقود `team_package/api_contract/`.
